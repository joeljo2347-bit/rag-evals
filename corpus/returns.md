# Returns

## Returns for credit
Sealed products can be returned for account credit within 30 days of delivery. A 15% restocking fee applies. Refunds to the original card are not offered; returns are always credited to the practice account.

## Wrong or damaged items
If we shipped the wrong item or it arrived damaged, report it within 7 days. We replace it at no charge and send a prepaid return label. No restocking fee applies.
